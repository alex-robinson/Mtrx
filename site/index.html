Matrix chat, native and quick

Mtrx is a desktop client for Matrix, written in Rust. It is a real app, not a web page in a wrapper, with what research groups need: messages sent later, LaTeX math, notes to self, PDFs and call links.

Download View source

Send later

Write now, send tomorrow at nine. Pick a time in one click, see what is queued above the message box, and edit, reschedule or send it now.

Matrix servers cannot schedule messages yet, so Mtrx keeps scheduled messages on your device (encrypted) and sends them while Mtrx, or mtrx watch, is running. If the time passes while neither runs, the message waits as overdue until you send or cancel it.

Math, typeset

Write $\dot m = \frac{G}{\rho L}$ and everyone sees the formula, typeset with Typst. Select text across messages and formulas, and copy it with the LaTeX intact, or copy a message as a picture.

Notes to self

Your notes stay at the top of the room list in every space. Export them as Markdown with mtrx notes.

Your room list, your way

Categories per space, favourites, low priority, unread first, and a colour for each space. They sync to your other devices.

PDFs and pictures

Open PDFs in a zoomable viewer, view pictures large, copy or save them.

Calls by link

Jitsi, Google Meet and Zoom links become a Join button. Give a room a standing call link, or start a new call with your space's service.

Keeps working offline

Messages show the moment you send them and go out when you are back online.

A command line too

mtrx reads, sends, schedules and watches rooms from the terminal, with the same account.

Encrypted

End-to-end encryption, device verification with emoji and key backup, from the matrix-rust-sdk.

Open source

Free software under the GNU AGPL: what is built on Mtrx stays open too. Works with any Matrix server, including matrix.org and your institute's.

Download

macOS

For Macs with Apple silicon.

Download Mtrx for Mac
First start

Mtrx is not signed by Apple yet, so macOS blocks it the first time. Unzip it, drag Mtrx to Applications and open it; then open System Settings → Privacy & Security and click Open Anyway. Or, in Terminal:

xattr -dr com.apple.quarantine /Applications/Mtrx.app

Windows

For 64-bit Windows 10 and 11.

Download Mtrx for Windows

Portable zip, without installing

First start

Mtrx is not signed yet, so Windows SmartScreen warns the first time: click More info, then Run anyway. The installer needs no administrator rights.

Linux

A .deb for Ubuntu 22.04 or later, and Debian.

Download Mtrx for Linux

AppImage, for other x86-64 distributions

First start

Install the .deb with

sudo apt install ./Mtrx-linux-amd64.deb

or make the AppImage executable (chmod +x) and run it. Mtrx keeps your sign-in in the system keyring, so it needs GNOME Keyring or KWallet.

The Windows and Linux versions are new: they are built and tested automatically, but have not yet been tried much on real machines. Problems and feedback are welcome as issues.

All versions are on the releases page. To build it yourself, see the README.
