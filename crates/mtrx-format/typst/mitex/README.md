Typst definitions for the output of the `mitex` LaTeX-to-Typst converter,
vendored from the `@preview/mitex:0.2.4` package (Apache-2.0, see LICENSE,
https://github.com/mitex-rs/mitex). Change: `latex/standard.typ` defines its
own `xarrow` instead of importing the GPL-licensed `@preview/xarrow`, and
`\KaTeX` no longer uses the `kai` symbol (removed in Typst 0.15).
